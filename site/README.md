# FrostWalker public project page

Static public presentation and interactive product trailer for FrostWalker.

## Local preview

From this directory, run any static HTTP server, for example:

```bash
python3 -m http.server 4173
```

Open `http://localhost:4173`. The trailer is available at `/trailer/`.

## Cloudflare Pages

- Repository root: `/`
- Build command: leave empty
- Build output directory: `site`

No credentials, tracking scripts, or private account data are included in this site.
